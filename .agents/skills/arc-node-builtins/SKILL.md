# ARC Built-in Node Types

ARC provides higher-order node wrappers for use in cluster definitions. See `/arc-nodes` for authoring plain nodes and `/arc-dsl` for cluster wiring syntax.

## Runtime Polymorphism

| Type | Cluster usage | Description |
|------|--------------|-------------|
| `arc::Union<Node1, Node2, ...>` | `animal = arc::Union<node::Cow, node::Sheep>` | Closed set of alternatives, stack-allocated (like `std::variant`). `emplace<Type>(args...)` to swap at runtime. Only a branch per external call. |
| `arc::Virtual<INode>` | `animal = arc::Virtual<node::IAnimal>` | Open set of implementations, heap-allocated with vtable dispatch. Interface derives from `arc::INode`. Supports hot-swap with detached handover. |
| `arc::Adapt<StaticNode, Facade>` | Runtime: `graph.virt->emplace<arc::Adapt<Fox, IAnimalFacade>>()` | Wraps a static node to present it as a `Virtual` implementation via a facade. |
| `arc::Box<Main, InFacade, OutFacade>` | Runtime like `Adapt` | Like `Adapt` but also virtualises the node's own dependencies behind an `OutFacade`. Fully isolated pluggable component. |

**Tip:** `arc::Virtual` can be an alternative inside `arc::Union` for best of both worlds — known types get fast branch dispatch, fallback gets vtable dispatch.

## Data Management

| Type | Cluster usage | Description |
|------|--------------|-------------|
| `arc::node::DataStore<SharedData, Map>` | `store = arc::node::DataStore<MyData, std::map>` | Keyed shared data store with listener notification. See [DataStore](#datastore) below. |

## Collections & Repetition

| Type | Cluster usage | Description |
|------|--------------|-------------|
| `arc::StaticMap<Node, ID>` | `elements = node::Element : arc::StaticMap<std::string>` | Fixed-capacity collection of identically-typed nodes keyed by caller-chosen unique IDs. Elements added at construction only. See [Collections](#collections) below. |
| `arc::DynamicMap<Node, ID>` | `elements = node::Element : arc::DynamicMap<std::string>` | As `StaticMap`, but elements can be inserted and removed at runtime (heap-allocated, stable handles). |
| `arc::StaticIndex<Node, ID = std::size_t>` | `elements = node::Element : arc::StaticIndex` | Fixed-capacity collection where IDs are indices assigned automatically on insertion (`arc::autoId`). ID must be an unsigned integral. |
| `arc::DynamicIndex<Node, ID = std::size_t>` | `elements = node::Element : arc::DynamicIndex` | As `StaticIndex`, with runtime insert/remove; freed indices are reused. |
| `arc::Repeater<Trait, N>` | Auto-generated by fan-out: `.. --> {a, b, c}` | N copies of a trait from one node. Access via `key::repeaterIndex<I>` or `key::repeaterNode<NodeType>`. |

## Threading

| Type | Cluster usage | Description |
|------|--------------|-------------|
| `arc::OnThread<Node, ThreadId>` | `ui = node::UI : arc::OnThread<0>` | Compile-time thread affinity. Access from wrong thread posts to scheduler. Thread 0 = main. |
| `arc::AnyThread<Node>` | `shared = node::Shared : arc::AnyThread` | No thread restriction — accessible from any thread. |
| `arc::OnDynThread<Node>` | `worker = node::Worker : arc::OnDynThread` | Thread ID assigned at construction time. |

## Debugging & Observability

| Type | Cluster usage | Description |
|------|--------------|-------------|
| `arc::TracerSpy` | `arc::GraphWithGlobal<cluster::App, arc::TracerSpy>` (as global) | Built-in `arc::trait::Spy` implementation. Records every intercepted trait call into an `arc::CircularBuffer` event log (id, parent, depth, method, args, return, timing, exceptions); oldest events evict on overflow while per-method stats stay accurate. Render on demand as JSONL or human-readable text via `write(os, Format)`. Designed for agentic debugging of integration tests. See [docs/tracer-spy.md](../../../docs/tracer-spy.md). |

## Access Control & Composition

| Type | Cluster usage | Description |
|------|--------------|-------------|
| `arc::InGroup<Node, Group...>` | `secret = node::Secret : arc::InGroup<policy::Level::HIGH>` | Assigns node to policy group(s) for compile-time access control. |
| `arc::Narrow<Node, Trait...>` | `restricted = arc::Narrow<node::Full, trait::Public>` | Exposes only a subset of a node's traits, hiding the rest. |
| `arc::Combine<Node1, Node2, ...>` | `bundle = arc::Combine<node::A, node::B>` | Groups multiple nodes into one, exposing all their traits. Access components via `get<NodeType>()`. |
| `arc::Lazy<Node>` | `expensive = arc::Lazy<node::Heavy>` | Defers construction until first access. One-time init. |

## Interfaces for Virtual Nodes

```cpp
// Define an interface for arc::Virtual
struct IAnimal : arc::INode
{
    using Traits = arc::Traits<trait::Animal>;
    virtual std::string impl(trait::Animal::speak) const = 0;
    virtual void impl(trait::Animal::evolve) = 0;
};

// Shorthand when interface just forwards trait methods
struct IColour : arc::INodeImpl<trait::Colour>
{
    virtual std::string getColour() const = 0;
};

// Combine multiple interfaces
using IColouredAnimal = arc::INodeOf<IAnimal, IColour>;
```

## DataStore

`arc::node::DataStore<SharedData, MapTemplate>` manages a keyed collection of shared data with automatic listener notification. Implements `arc::trait::DataStore<SharedData>` and depends on `arc::trait::DataListener<SharedData>`.

**SharedData** must define an `Id` type (used as the map key).

**Cluster wiring** — the store connects bidirectionally to its listeners via a repeater:
```arc
using DataStore = arc::DataStore<MySharedData>
using DataListener = arc::DataListener<MySharedData>

cluster MyCluster [Root]
{
    store = arc::node::DataStore<MySharedData, std::map>
    listenerA = node::ListenerA
    listenerB = Root::ListenerB

    [DataStore <-> DataListener]
    store <-> {listenerA, listenerB}
}
```

**DataStore trait API** (called by listeners via `getDataStore()`):
- `add(id, args...)` — emplace SharedData; listeners' `init` is called, only stored if at least one subscribes. Returns `{SharedData*, wasNewlySubscribed}`.
- `get(id)` / `get(sharedDataPtr)` — lookup by ID or pointer. Returns `{SharedData*, PrivateData*}` (PrivateData is per-listener).
- `modify(id, fn)` — call `fn(SharedData*, PrivateData*)` which returns an event (or `void`/`arc::noEvent` for no notification). Other listeners receive `onEvent`. Caller is skipped.
- `forEach(fn)` — iterate all entries. `fn(id, SharedData*, PrivateData*)` may return an event to notify.
- `notify(event, id)` / `notifyAll(event)` — push an event to listeners without modifying data.

**DataListener trait** — implemented by listener nodes:
- `init(id, SharedData&, constructor)` — called when data is added. Call `constructor(args...)` to subscribe (creates PrivateData). Return `PrivateData` directly to unconditionally subscribe to all IDs.
- `onEvent(Event<T>, EventItem<SharedData, PrivateData>)` — called on notification. Return `false` to stop propagation.
- `skipEvent(event, item)` — optional; return `true` to skip this event. Useful: `return not event.isLatest();`

**Event types:**
- Return an event type from `modify`/`forEach` lambdas to notify listeners
- `arc::noEvent` or `void` return — no notification
- `std::optional<Event>` — notify only if has value
- `Event::isLatest()` — check if this event is still the most recent for this ID
- `arc::NoPrivateData` — use as `PrivateData` type when listener needs no per-entry state

## Collections

Four collection node aliases manage identically-typed element nodes, each identified by a unique ID:

- `arc::StaticMap<NodeHandle, ID>` — caller-chosen IDs; fixed capacity, elements added at construction only
- `arc::DynamicMap<NodeHandle, ID>` — caller-chosen IDs; runtime `insert`/`remove` (elements heap-allocated, stable handles)
- `arc::StaticIndex<NodeHandle, ID = std::size_t>` — IDs are indices assigned automatically on insertion; fixed capacity
- `arc::DynamicIndex<NodeHandle, ID = std::size_t>` — auto-assigned indices; runtime insert/remove, freed indices reused

Index collections require an unsigned integral ID and take `arc::autoId` in place of an ID when inserting — the assigned id is the element's index.

**Cluster wiring:**
```arc
cluster MyCluster
{
    elements = node::Element : arc::StaticMap<std::string>
    manager = node::Manager

    [ElementTrait]
    manager --> elements
}
```

**Construction** — static collections take a capacity and an adder callable:
```cpp
arc::Graph<cluster::MyCluster> graph{
    .elements{3, [](auto add) {
        add("alice");
        add("bob");
        add("charlie");
    }}
};
```
The `add` callable takes `(ID const& id, auto&&... args)` where extra args are forwarded to the element node's constructor (for index collections: `add(arc::autoId, args...)`). Exceeding capacity or adding duplicate IDs throws. Dynamic collections are default-constructible and add elements via `insert`.

**Collection API** (on the collection node itself, not via traits):
- `contains(id)` — returns `bool`, whether an element with this ID exists
- `getId(id)` — returns pointer to element node, or `nullptr` if not found
- `atId(id)` — returns reference to element node, throws `std::out_of_range` if not found
- Dynamic only: `insert(id, args...)` (throws on duplicate), `tryInsert(id, args...)`, `remove(id)`, `removeIf(pred)`, `forEach(func)` — index variants take `arc::autoId` instead of an id when inserting. `insert`/`tryInsert` return a pointer that is `nullptr` if the storage cannot accommodate the element (e.g. index id space exhausted).

**Storage policy** — layout is pluggable: `arc::Collection<NodeHandle, ID, Policy>` with `arc::CollectionPolicy<Dynamic, StorageTemplate>`. `VectorStorage` backs the Map aliases, `IndexStorage` the Index aliases. Custom storages implement the `arc::IsCollectionStorage` / `arc::IsDynamicCollectionStorage` concepts.

**Accessing elements via traits** — use keys in `getNode()`:
```cpp
// Single element by ID
auto elem = self.getNode(trait::element, key::Element(myId));

// All elements
self.getNode(trait::element, key::allElements).forEach([](auto& elem) { ... });

// Filtered elements
self.getNode(trait::element, key::Elements([](auto const& id) { return id != "skip"; }));
```

**Handle** — `getElementHandle()` returns an opaque handle (index for static storage, shared ownership for dynamic) that can be used with `key::Element(handle)` for faster access than ID lookup.

## PeerNode

`arc::PeerNode` is a base class for nodes inside a collection (Map/Index) that need to discover and interact with sibling elements. It extends `arc::Node` with collection-aware methods.

**Usage** — derive from `PeerNode` instead of `Node`:
```cpp
export struct MyElement : arc::PeerNode::
    Uses<trait::SomeDep>::
    Impl<trait::ElementTrait>
{
    auto myMethod(this auto& self)
    {
        auto const& id = self.getElementId();
        auto handle = self.getElementHandle();

        // Iterate peer elements (same collection, excluding self)
        for (auto const& peer : self.getPeers())
        {
            // peer is a const ref to a sibling node
        }
    }
};
```

**PeerNode API:**
- `getElementId()` — returns `const&` to this element's ID within the collection
- `getElementHandle()` — returns an opaque `Handle` for efficient re-access via `key::Element(handle)`
- `getPeers()` — returns a filtered range of sibling nodes (excludes self). Requires the node to implement `arc::trait::Peer`

**Peer trait** — controls which siblings are visible as peers:
```arc
trait arc::trait::Peer
{
    isPeerId(auto const& id) const    // Filter by sibling ID
    isPeerInstance(auto const& node) const  // Filter by sibling node instance
}
```

Default implementations:
- `PeerNode` — rejects all peers (both methods return `false`)
- `PeerDetached` — detached trait impl rejects all peers (for detached/virtual contexts)
- `PeerDetachedOpen` — detached trait impl accepts all peers (both methods return `true`)

Override `impl(trait::Peer::isPeerId, ...)` and `impl(trait::Peer::isPeerInstance, ...)` to customise peer visibility.

## Spy Trait

`arc::trait::Spy` allows transparent interception of all trait method calls for logging, profiling, validation, or testing — without modifying implementation code. Similar to Aspect-Oriented Programming.

**Setup** — create a global spy node:
```cpp
struct MySpy : arc::Node
{
    using Traits = arc::Traits<arc::trait::Spy>;

    template<class Method, class... Args>
    decltype(auto) impl(arc::trait::Spy::intercept, Method, auto impl_fn, Args&&... args)
    {
        ++callCount;
        return impl_fn(std::forward<Args>(args)...);
    }
    int callCount = 0;
};
```

**Use with `GraphWithGlobal`:**
```cpp
arc::GraphWithGlobal<cluster::MyCluster, MySpy> graph{ .global{}, .main{...} };
```

**Targeted spying** — intercept only specific traits:
```cpp
using Traits = arc::Traits<arc::trait::SpyOnly<trait::Storage>>;
```

**Daisy-chaining** — compose multiple spies in a global cluster:
```arc
cluster GlobalSpies
{
    logger = LoggerSpy
    profiler = ProfilingSpy

    [arc::trait::Spy]
    .. --> logger --> profiler
}
```

Zero overhead when no spy is present. Use for testing, profiling, audit logging, input validation, or debug tracing.

## TracerSpy

Turnkey global spy for integration tests — the easy path before writing a custom `arc::trait::Spy`.

```cpp
arc::GraphWithGlobal<cluster::App, arc::TracerSpy> graph{ .global{{.recording = true}}, .main{ /* ... */ } };

graph->api.asTrait(trait::request).handle("GET", "/items/42");

graph.global->write(std::cout, arc::TracerSpy::Format::Human);   // indented tree + summary
graph.global->write(file,      arc::TracerSpy::Format::Jsonl);   // JSONL for agents / diffing
```

**Key properties:**
- Format-agnostic recording; render on demand via `write` / `writeTrace` / `writeSummary`.
- Ring buffer (`CircularBuffer<Event>`, default cap 32 Ki); oldest events evict on overflow. Per-method `Stats` survive eviction — `summary_meta` reports `events_evicted`.
- Each event: `id`+`parent` (call tree), `depth`, `node` handle type, args/return (best-effort `std::formattable`), timing.
- `startRecording()`/`stopRecording()` — hard bypass; zero stats/id overhead when paused. Nodes inside the graph can scope tracing via `self.getGlobal(arc::trait::spy).enable()`/`.disable()`.
- `Params`: `minDepth`/`maxDepth` filter noise, `maxEvents` sizes ring, `recording=false` pauses recording.
- `reset(Params)` clears all state and applies new Params; `reset()` keeps current Params.
- Accessors: `getEvents()`, `getStats()`, `getTotalCalls()`, `getMaxDepthSeen()`.
- For golden-file diffing, size `maxEvents` above expected event count to avoid prefix drift.

Full reference and JSONL schema: [docs/tracer-spy.md](../../../docs/tracer-spy.md).

## Keys

Keys disambiguate `getNode()` calls when a trait resolves to multiple nodes (repeaters, collections, etc.).

```cpp
// Default: no key needed for 1:1 trait connections
auto logger = self.getLogger();                     // from Uses<trait::Logger>
auto logger = self.getNode(trait::logger);          // equivalent

// Repeater keys: when a trait fans out to multiple nodes
auto first  = self.getNode(trait::target, key::repeaterIndex<0>);
auto second = self.getNode(trait::target, key::repeaterIndex<1>);
auto byType = self.getNode(trait::target, key::repeaterNode<node::Specific>);

// Collection keys: access elements by ID
auto elem = self.getNode(trait::element, key::Element(myId));

// By handle (faster, no ID lookup)
auto handle = self.getElementHandle();
auto elem = self.getNode(trait::element, key::Element(handle));

// Iterate all collection elements
self.getNode(trait::element, key::allElements).forEach([](auto& elem) { ... });

// Filter collection elements by predicate on ID
self.getNode(trait::element, key::Elements([](auto const& id) { return pred; }));
```
